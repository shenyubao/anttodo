# 单点登录

团队空间的所有者和管理员可为当前团队空间配置企业单点登录（SSO）。配置完成后，成员可通过钉钉扫码登录并加入该团队空间。

## 钉钉登录

在 AntTodo 中使用钉钉企业内部应用登录前，请先在钉钉开放平台创建并配置企业内部应用，再将凭证填写到团队空间的「设置 → 单点登录」。

### 1. 获取 CorpId

1. 使用企业管理员账号登录 [钉钉开放平台](https://open-dev.dingtalk.com/)。
2. 进入开发者后台后，在首页查看当前企业的 **CorpId**（企业标识）。

CorpId 是企业在钉钉中的唯一标识，通常形如 `dingxxxxxxxxxx`。

### 2. 获取 AppKey 与 AppSecret

1. 在钉钉开放平台进入目标**企业内部应用**的应用详情。
2. 打开 **基础信息 → 凭证与基础信息**。
3. 复制 **AppKey**（Client ID）与 **AppSecret**。

AppSecret 仅在配置时写入 AntTodo，不会在界面上回显明文。

### 3. 配置重定向 URL

1. 在应用详情中打开 **开发配置 → 安全设置**。
2. 将重定向 URL / 回调地址配置为：

```text
https://app.anttodo.com/auth/dingtalk/callback
```

请使用与线上应用一致的地址；本地调试时需按实际公网回调域名另行配置。

### 4. 申请权限

1. 在应用详情中打开 **权限管理**。
2. 申请并开通以下权限：
   - `Contact.User.mobile`：读取用户手机号（用于匹配或创建 AntTodo 账号）
   - `Contact.User.Read`：读取用户基本信息

未开通上述权限时，扫码登录可能成功，但无法完成用户信息换取与账号关联。

### 5. 发布应用

1. 在钉钉开发者后台完成上述配置后，进入应用的 **版本管理与发布**（或「发布」相关入口）。
2. 创建并提交应用版本，将应用发布到企业内可用状态。

仅完成开发配置而未发布时，企业成员通常无法正常使用该应用完成扫码登录。

### 在 AntTodo 中完成配置

取得上述信息并完成权限申请与应用发布后：

1. 以所有者或管理员身份打开对应团队空间。
2. 进入 **设置 → 单点登录**，选择「钉钉企业登录」并填写：
   - CorpId
   - AppKey
   - AppSecret
   - AgentId（可选）
3. 保存时请确保 **AppKey 与 AppSecret 来自同一应用**。更换 AppKey 后必须重新填写 AppSecret；仅改 AppKey 会导致扫码成功但回调换票失败。
4. 保存后，将团队域名分享给成员。成员访问 `{团队Slug}.team.anttodo.com` 时，仅可使用钉钉扫码登录；主站 `app.anttodo.com` 仅提供手机号登录。

### 团队登录域名

每个团队空间拥有唯一 Slug，并对应三级域名：

```text
https://{团队Slug}.team.anttodo.com/
```

例如 Slug 为 `yucekj` 时，登录入口为 `https://yucekj.team.anttodo.com/`。

钉钉 OAuth 回调仍固定为：

```text
https://app.anttodo.com/auth/dingtalk/callback
```

可在「设置 → 团队管理」查看域名，或在「设置 → 单点登录」复制团队登录域名。
